# План: переработка вкладки «Ручная разборка»

## Текущие проблемы и причины


| Проблема                                               | Причина                                                                                                                                                                                                                                                                                                                                      |
| ------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Название в первом столбце не отображается              | Хрупкая цепочка привязок: делегат берёт данные как `parent.parent.t` (Row → ItemDelegate). При перестроении модели или обновлении `ExtractionController.tracks` привязка к `trackData`/индексу может не пересчитаться; плюс в модели только `trackIndex`, а не полный объект дорожки.                                                        |
| «Выбрать все» и стрелка сжаты                          | Один RowLayout с стрелкой, названием группы и двумя кнопками в одной строке без минимальных ширин; при нехватке места всё сжимается в одну кучу.                                                                                                                                                                                             |
| Ресайз столбцов не работает + предупреждение в консоли | В Qt 6 не рекомендуется неявная инъекция параметра `mouse` в обработчики сигналов. Код использует `onPressed: { ... mouse.x ... }` и `onPositionChanged: if (pressed) ... mouse.x ...` без формального параметра, из‑за чего (1) выдаётся предупреждение и (2) в новых версиях `mouse` может быть недоступен, логика ресайза не срабатывает. |


## Рекомендуемый подход: точечная переработка без смены C++

Переписать только [ui/qml/pages/ExtractionPage.qml](ui/qml/pages/ExtractionPage.qml), оставив [src/core/extractioncontroller.cpp](src/core/extractioncontroller.cpp) и [src/core/extractioncontroller.h](src/core/extractioncontroller.h) без изменений.

### 1. Модель: самодостаточные элементы (без lookup по индексу в делегате)

Сейчас `displayModel` для дорожек хранит только `{ isSection: false, trackIndex: j }`, а делегат достаёт данные из `ExtractionController.tracks[trackIndex]`, из‑за чего привязки к первому столбцу ненадёжны.

**Сделать:** при построении `displayModel` для каждой дорожки класть в элемент полную копию полей, нужных для отображения и для обратного вызова:

- Секция: `{ isSection: true, group: "Видео" }` — без изменений.
- Дорожка: `{ isSection: false, trackIndex: j, displayName: t.displayName, id: t.id, ext: t.ext, lang: t.lang, info: t.info, checked: t.checked }` (при необходимости добавить `isAttachment`, `attachmentName` для колонки «Информация»).

В делегате строки дорожки использовать только `modelData`: например `modelData.displayName`, `modelData.checked`, а при изменении чекбокса вызывать `ExtractionController.setTrackChecked(modelData.trackIndex, checked)`. Так исчезнет зависимость от `parent.parent.t` и привязки к первому столбцу станут стабильными.

### 2. Ресайз столбцов: формальные параметры в обработчиках мыши

Во всех `MouseArea` в заголовке таблицы заменить неявное использование `mouse` на явный параметр:

- `onPressed: (mouse) => { headerRow.dragStartX = mouse.x; headerRow.dragStartWidth = root.colExtract }`
- `onPositionChanged: (mouse) => { if (pressed) root.colExtract = Math.max(50, headerRow.dragStartWidth + mouse.x - headerRow.dragStartX) }`

Аналогично для остальных трёх столбцов (colId, colType, colLang). Так предупреждение исчезнет и изменение ширины столбцов начнёт работать.

При желании можно вынести один «ресайзер» в небольшой компонент (например, `ColumnResizer` с привязкой к свойству ширины и минимуму), чтобы не дублировать один и тот же блок четырежды.

### 3. Секция (Видео / Аудио / …): разделить стрелку/название и кнопки

Чтобы «Выбрать все» и стрелка раскрытия не сжимались в одно место:

- **Вариант A (предпочтительный):** две строки внутри делегата секции.
  - Верхняя: стрелка (▶/▼) + название группы; по клику на эту область — переключение свёрнуто/развёрнуто.
  - Нижняя: кнопки «Выбрать все» и «Снять все» с фиксированными отступами и минимальной высотой (например, 28–32 px).
- Высота делегата секции: например 52–56 px, чтобы обе строки помещались без наложения.

Альтернатива — одна строка, но у кнопок задать `Layout.minimumWidth` и увеличить высоту строки секции (например, до 44–48 px), чтобы кнопки не сжимались; двухстрочный вариант даёт более предсказуемый результат.

### 4. Делегат строки дорожки: упростить разметку

- Убрать вложенность с `parent.parent.t`: в первой ячейке один Row с CheckBox и Label.
- Текст названия: `text: modelData.displayName || modelData.group || ""`, ширина Label — по оставшемуся месту в первой колонке (например, `root.colExtract - 40`).
- Остальные ячейки — те же поля из `modelData` (id, ext, lang, info) с теми же привязками к ширинам столбцов.

После этого первый столбец будет однозначно привязан к данным из модели, без косвенных ссылок через родителя.

### 5. Порядок работ (кратко)

1. В `rebuildDisplayModel()` для каждой дорожки пушить в список объект с полями `trackIndex`, `displayName`, `id`, `ext`, `lang`, `info`, `checked` (и при необходимости для вложений).
2. В делегате дорожки перейти на чтение только из `modelData` и вызов `setTrackChecked(modelData.trackIndex, checked)`.
3. Во всех MouseArea заголовка таблицы заменить обработчики на формы с формальным параметром `(mouse) => { ... }`.
4. Перестроить делегат секции: два ряда (стрелка+название; кнопки) и достаточная высота делегата.
5. Проверить, что при изменении выбора в C++ (setTrackChecked/setGroupChecked) список дорожек обновляется и `rebuildDisplayModel()` вызывается по `tracksChanged`, чтобы чекбоксы и названия оставались синхронными.

## Что не менять

- **ExtractionController (C++):** API и формат `tracks` (QVariantList с полями id, group, lang, ext, info, displayName, isAttachment, attachmentName, checked) оставить как есть.
- **Общая структура страницы:** блок файла, таблица дорожек, чекбокс «Извлечь шрифты», журнал, прогресс, кнопка «НАЧАТЬ РАЗБОР» — без изменений.
- **Количество и названия столбцов:** Извлечь/Название, ID, Тип, Язык, Информация — как в старом GUI.

## Итог

Переписать только QML: самодостаточная плоская модель для списка, корректные обработчики мыши для ресайза, двухстрочный заголовок секции и простые привязки в делегате к `modelData`. Это устраняет все три заявленные проблемы без введения TableView или новых C++ моделей.
