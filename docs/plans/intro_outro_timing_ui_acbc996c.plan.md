# План: тайминги всех глав для заливки

## Что реализуем

- Добавлю извлечение **всех** глав из уже загруженного списка (`ChapterMarker`) с вычислением `start/end` в секундах.
- В **автоматическом режиме** выведу список глав в виджете публикации: `название`, `начало`, `конец`.
- В **ручном режиме** добавлю отдельное окно с тем же списком.
- Для каждой главы будут отдельные кнопки копирования `начала` и `конца` (по одному числу).
- Если главы отсутствуют, блок с таймингами не показывается (или отображается пустое состояние — на этапе реализации выберем самый аккуратный UI-вариант).

## Детали поведения

- Формируем универсальную модель элемента списка: `title`, `startSeconds`, `endSeconds`.
- `start`/`end` берем из информации главы; если явного `end` нет, рассчитываем `end` по следующей главе с безопасным fallback для последней главы.
- Конвертация в целые секунды для сайта.
- Для каждой строки доступны отдельные кнопки копирования `start` и `end` в буфер (`QApplication::clipboard()->setText`).
- Никакой жесткой логики OP/ED/intro/outro не добавляем: только список фактических глав.

## Проверка

- Прогон на файле с несколькими главами: отображается список всех глав и копирование `start/end` по каждой.
- Прогон на файле с нестандартными названиями глав: названия выводятся как есть, без фильтрации по OP/ED.
- Прогон на файле без глав: блок не показывается или отображается понятное пустое состояние.
- Проверка ручного режима: открытие окна и идентичное поведение копирования.
- Быстрая проверка линтеров по измененным файлам.
